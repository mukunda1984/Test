# InsightFlow — GitHub Pages site

A responsive static landing page for a small-business analytics / BI service.

## Deploy to GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and `styles.css` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
4. Replace `hello@yourdomain.com` in `index.html` with your email.
5. Replace the `InsightFlow` brand name if desired.

No build process or backend is required.
